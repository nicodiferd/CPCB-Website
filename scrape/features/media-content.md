## Image Optimization

### Optimization Techniques

**Compression:**
- JPEG: 80-85% quality
- PNG: TinyPNG or similar
- WebP: Modern format, better compression

**Responsive Images:**
- Multiple sizes for different screen widths
- `srcset` attribute for resolution switching
- `picture` element for art direction

**Lazy Loading:**
- Native `loading="lazy"` attribute
- JavaScript fallback for older browsers
- Placeholder while loading (blur-up, skeleton)

**Example:**
```html
<img
  src="game-photo-800.jpg"
  srcset="game-photo-400.jpg 400w,
          game-photo-800.jpg 800w,
          game-photo-1200.jpg 1200w"
  sizes="(max-width: 600px) 400px,
         (max-width: 1000px) 800px,
         1200px"
  alt="Cal Poly player hitting home run against UCLA"
  loading="lazy"
>
```

## Accessibility Considerations

### Images
- **Alt Text:** Descriptive, concise (125 characters max)
- **Decorative Images:** Empty alt (`alt=""`)
- **Complex Images:** Long description via `aria-describedby`
- **Text in Images:** Avoid or provide text alternative

**Example Alt Text:**
- Good: "Cal Poly batter swinging at pitch during home game against UCSB"
- Bad: "Image123.jpg" or "Baseball game"

### Videos
- **Captions:** Closed captions for dialogue and important sounds
- **Transcripts:** Full text transcript available
- **Audio Description:** Describe visual content for blind users
- **Controls:** Keyboard accessible play/pause

### Icons
- **ARIA Labels:** Icon-only buttons need labels
- **Example:** `<button aria-label="Instagram"><svg>...</svg></button>`
